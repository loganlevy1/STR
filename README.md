# STR Investor Outreach Strategy

Repo for Cliffco Mortgage Bankers' strategy to expand our real estate investor
loan-officer pipeline beyond Michael Chang's audience, by identifying and
partnering with other small-to-medium educators serving the same type of
client (real estate investors/developers who need DSCR, fix-and-flip/bridge,
construction, and portfolio financing).

## Why

We've built a highly successful pipeline servicing Michael Chang's webinar
audience — real estate investors and developers who come to him for
education and, through us, get financed. This repo tracks the effort to find
and reach similarly-sized educators (in audience and engagement, not the
mega-brand tier like BiggerPockets or Grant Cardone) across every major
investor niche, and to turn those relationships into the same kind of
pipeline.

## Contents

- `reports/Real estate investor educator targets.md` — the first deep-research
  deliverable: ~70 named small-to-medium real estate investment educators
  across STR/Airbnb, BRRRR/buy-and-hold/DSCR, fix-and-flip/wholesaling, and
  multifamily/development, with a consolidated target table (audience size,
  loan-product fit, contact info, verification status), reputational/compliance
  flags to avoid, and suggested outreach mechanisms.
- `research_notes/` — the underlying per-niche research notes the report was
  synthesized from, kept for traceability and follow-up research.
- `brand/` — Cliffco Mortgage Bankers branding (logos, brand guide,
  mission/vision/values, color + typography tokens) for use in outreach
  materials. See `brand/README.md`.
- `compliance/` — Cliffco compliance source of truth (state licenses, branch
  offices, loan-officer roster, disclosure language) for any compliance-required
  copy in outreach materials. See `compliance/README.md`.

## Status

The target roster in the report is a first pass built from public web
research. Most audience-size figures are marked "needs manual verification" —
confirm live follower/subscriber counts and current contact info directly on
each educator's own channels before using this list for outreach.

A follow-up research pass added likely business home base (HQ) and
publicly-published contact info (phone/email/mailing address, sourced from
each business's own site, BBB profiles, and corporate filings — never
people-search or residential records) for all ~70 names. Per-name detail is
in each niche file under `research_notes/`; a consolidated view plus a
NY/CT/NJ regional pull is in the report's "Home base and public contact
info" section.

## Next steps

- Manually verify the "confirmed" and near-confirmed names first — they're
  the highest-confidence, lowest-effort targets to start outreach with.
- Stand up outreach tracking (CRM board or spreadsheet) from the target table.
- Draft outreach templates per mechanism (affiliate/referral, sponsored
  webinar, preferred-lender placement, REIA/mastermind sponsorship).
