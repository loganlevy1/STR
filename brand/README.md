# Cliffco Brand Assets

Cliffco Mortgage Bankers branding, copied from the Cliffco site repo
(`cliffcomortgage/cliffco-site`) for use in STR investor-outreach materials
(decks, emails, one-pagers, microsites). Keep this folder in sync if the
canonical assets in the site repo change.

## What's here

- `mission-vision-values.md` / `.docx` — canonical mission, vision, and values.
- `brand-guide.pdf` — full brand guide (colors, typography, voice, usage).
- `design-tokens.css` — the color + typography tokens as CSS custom properties,
  extracted from the brand guide and the live site's `global.css`.
- `logos/` — logo lockups and marks:
  - `full/` — full logo (black + white PNG).
  - `icon/` — icon mark (black + white PNG).
  - `favicon/` — favicon (PNG + SVG).
  - `source-ai/` — editable Adobe Illustrator source files.
  - `EHO_White.png` — Equal Housing Opportunity mark (white).

## Brand pillars (drive every outreach message)

- **Vision:** To be the lender every family wishes they'd called first.
- **Mission:** We get families home. Especially the ones other banks turned
  away. And we grow their net worth and self-worth along the way.
- **Values:** Family · Integrity · Care · Possibility.
- **Voice:** warm, human, scrappy. Explicitly anti-call-center,
  pro-second-chance-borrower — "yes when other banks say no." Avoid
  corporate/banky/cold language.

## Typography

Production web typeface is **Open Sans** (decision 2026-07-16). The brand
guide's primary typeface is Graphik, but its trial OTFs are not licensed for
web use, so the published web fallback (Open Sans) ships instead. Logo
wordmark uses Montserrat with wide tracking.
